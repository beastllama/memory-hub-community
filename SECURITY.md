# Report a security issue

Use GitHub's **Report a vulnerability** option under **Security** if it is enabled. If it is not available, ask the maintainer for a private reporting channel before sharing details. Do not post a vulnerability, source excerpt, credential, or personal path in a public issue.

The preview is intended for one person on a trusted machine. It binds to the loopback interface. Do not forward its port or share its session URL. Local state is not encrypted by Memory Hub. Do not point it at folders you do not trust or use it as a sandbox for hostile code.
